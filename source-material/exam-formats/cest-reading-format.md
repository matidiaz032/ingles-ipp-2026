# CEST (Cambridge English Skills Test General) — Reading Format

**Fuente:** cambridgeenglish.org oficial (https://www.cambridgeenglish.org/es/exams-and-tests/cambridge-english-skills-test/general/)

## Datos generales

- **Duración:** 30–40 minutos aproximadamente (máximo 59 min)
- **Formato:** adaptativo, un solo examen para todos los niveles A1 a C1
- **Corrección:** automática, resultado inmediato
- **Público objetivo:** mayores de 16 años; diseñado para uso interno de instituciones (colocación de nivel, exámenes de mitad/fin de curso, verificación de si un alumno está listo para rendir Linguaskill o un Cambridge English Qualification)

## ⚠️ Dato clave para la decisión Linguaskill vs. CEST

**El CEST es solo para uso interno — no tiene reconocimiento externo como certificación.**
Cita textual de la fuente oficial: *"La prueba Cambridge English Skills Test es solo para uso interno y no tiene ningún reconocimiento externo. Para obtener una certificación reconocida de dominio del inglés, ofrecemos IELTS, Cambridge English Qualifications y Linguaskill."*

Esto sugiere que el CEST podría ser un paso de diagnóstico/práctica previo, no un objetivo final si la meta es tener una certificación que sirva para el currículum o para procesos de selección laboral.

## Tipos de tarea

La página oficial no detalla los task types específicos de Reading de la misma forma que Linguaskill (no hay un desglose público equivalente). Hay:
- Un examen de muestra (sample test) real navegable online
- Un PDF de claves de respuesta de la muestra
- Un PDF de "consejos para candidatos" de Reading
- Un PDF con la estructura/especificaciones completas del examen ("CEST General: Reading")

**Recursos oficiales para bajar (en inglés):**

## Comparación rápida con Linguaskill

| | CEST | Linguaskill |
|---|---|---|
| Duración Reading | 30–40 min aprox. (máx. 59) | hasta 59 min |
| Niveles | A1–C1 | B1–C2 |
| Reconocimiento | Solo interno | Certificado Cambridge válido |
| Task types documentados públicamente | No, en detalle | Sí, 9 tipos documentados |
